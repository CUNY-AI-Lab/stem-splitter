Teaching Tips

Build a listening task around one change to the mixer. Ask students to describe the sound before they name the musical concept.

Before the Semester

Split the core repertoire and place each unit's recordings in a shared folder. A prepared folder lets students begin with listening. Choose read-only access for a demonstration or allow students to add notes when the assignment needs annotations. Check the source's license and audio quality before sharing it.

Listen to each stem before assigning a label. If Other mainly contains a banjo in a bluegrass recording, you can rename it in Class settings so the class uses the same term. Keep any mixed contents in view when students describe the part.

Choose the vocabulary you want Listening Guy to use and put it in the Instructor Console. Begin with a concept students can test through a mixer action, such as whether two parts carry independent lines.

In Class

Play a passage with every stem, mute one layer, and replay it. Ask students to name the change before you introduce a definition. For a quick rhythmic figure, slow the passage to 0.5× and ask students to count it. They can then return to full speed and check whether they still hear the pattern.

Project your mixer during a live session so students can connect the controls to what they hear in headphones. Pin a note that gives them a next action. The demonstration's instruction to hear vocals and drums alone gives students a pair of parts to compare.

With Listening Guy

Ask students to treat each description as a claim they can test. Listening Guy cannot hear the audio, so a plausible account of a genre may miss the recording in front of them. Have students name the stem and timestamp that support or challenge its answer.

Read course conversations through the roster to see where students need help. If several students ask about the same term, return to a passage where the class can hear the distinction. Plan activities around the daily turn allowance; a task with two or three questions leaves room for a follow-up.

Assessment

Ask students to submit timestamped notes with the mixer state they used. A response that names the soloed stems and describes an audible change gives you a passage to review. Assess the description against that passage, and ask the student to revise when the evidence remains unclear.

A folder that allows class notes lets students compare section boundaries on the same recording. Invite them to explain a disagreement, then revisit the passage together. The playhead gives the class a shared point of reference for deciding where a bridge or chorus begins.

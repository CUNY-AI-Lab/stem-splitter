Dashboard

Manage your account and Listening Guy instructions, with class tools available according to your current permissions.

Open Dashboard

Choose CUNY Login below the Lab logo. After sign-in, the main menu shows Splitter, Workspace, and Dashboard. Dashboard contains Account and Listening Guy. An individual CUNY AI Lab user can use both without joining a class. Guest sessions do not have Dashboard access.

Account

Account shows your split allowance and the available Listening Guy and Lab model allowance information. Use the reset time shown in the app. You can also sign out or follow links to Lab resources here. Activity review and access-management controls appear only for accounts authorized to use them.

Where activity totals are available, recorded runs, completed splits, replies, and opening cues are separate counts. Browser visit and playback reports cover the past 30 days and can be incomplete. None recorded does not establish that someone never used the tool. Account added is the account record's creation date; browser activity, operation records, and authenticated requests have separate dates.

Personal and Class Instructions

Open Listening Guy and check Instructions for. Personal applies only to your own Personal work. Students and instructors can each keep Personal instructions. A class choice appears only when you have permission to open that class's instruction controls; editing also requires permission to save changes.

Class instructions apply to that class's work. They do not carry over to guest sessions or independent Personal work. Guest sessions use the base instructions. The notice above the editor identifies the current scope, so check it before saving.

The instruction field accepts up to 2,000 characters. Name the ideas you want to explore, your level of experience, and a useful listening question. Add a change note of up to 240 characters, then save. Each changed save requires a note and records a revision for the selected scope.

Preview saved prompt shows the saved instructions combined with the read-only base prompt. It does not send a model request. Prompt reference keeps the revisions and their change notes. To reset your instructions, clear the field and save with a note. Reload saved instructions replaces the editor with the last saved version.

Switching away from the browser and back preserves an unsaved draft while your identity and access remain valid. If the app reports an account or permission change, return through Dashboard and recheck access. Do not treat an uncertain save as confirmed; reload the saved instructions before retrying it.

Instructions to Test Through Listening

Begin with one concept, such as musical texture. For example: “Explain monophony and polyphony in plain language, then ask one question I can answer by muting a stem.” The instruction shapes a question; it does not give the model direct evidence from the audio. Listen to the stems and check the answer.

For a class, use language appropriate to the students and review only conversations you are permitted to see. Personal conversations remain private. Class Workspace explains class assignment, consent, and review access.

Search Examples

Accounts with application-level permission also see Search examples in the Personal view. These controls choose suggested songs for the search bar below upload. They do not limit the catalogs queried by search. Class membership or access to your own instructions does not grant permission to change these shared examples.

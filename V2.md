# What's new — instructor notes

App: https://stem-splitter.ailab-452.workers.dev

## Class code now checked at the door (July 2026)

When a student first opens the app, the class-code prompt now verifies the
code with the server immediately. A typo gets an instant "Invalid class code —
try again" re-prompt instead of a confusing failure on their first upload.

What this means for you:

- Tell students the code once; if they mistype it, the app itself corrects
  them on the spot.
- If a student clicks Cancel on the prompt, they can still *listen* to stems
  from a link a classmate shares (listening never requires the code), but they
  can't add songs until they reload and enter it.
- If you ever change the class code (`npx wrangler secret put CLASS_CODE`),
  students who had the old one saved are re-prompted automatically the next
  time the app checks — no need to have them clear anything.

## YouTube import

Students can paste a YouTube link instead of uploading a file. The app fetches
the audio (~1¢ per fetch on top of the usual separation cost) and runs the same
stem split. Limits: 15 minutes max, no live streams.

Note: keep the Replicate account balance above $5 — low-credit accounts get
rate-limited and imports slow down or fail.

## 4-stem vs 6-stem choice

Each song can be split into the standard 4 stems (vocals / drums / bass /
other) or 6 (adds guitar and piano). 6-stem runs cost slightly more and take a
bit longer. Students pick per song at submission.

## Shared labels and timestamped notes

- Click a channel name in the mixer to rename it (e.g. "other" → "synths").
- "＋ NOTE" stamps a comment at the current playback time; all notes appear in
  a list under the channels and as ticks on the seek bar. Click a timecode to
  jump there; hover a note to delete it.
- Labels and notes are shared: every student opening the same song link sees
  them. Good for leaving listening prompts on a song before class.
- Limit to know about: another student's edits appear only after a page
  reload.

## Housekeeping

- Songs and stems auto-delete from storage after 30 days (copyright
  retention policy — re-import if a song is needed next month).
- Costs: ~$0.045 per 4-stem song, ~1¢ extra for YouTube fetch; the first job
  after a quiet period takes an extra 30–60 s while the GPU model warms up
  (the UI warns students about this).

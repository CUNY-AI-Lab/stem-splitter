# Instructor-controlled song suggestions

Instructors with existing console access manage the search-field examples. Search Internet Archive by artist or title, select exact verified recordings, and arrange selected cards by dragging or keyboard/buttons. No link-entry field. Seed six musically diverse, complete recordings from the supplied playlists, spanning jazz, electronic, country, funk, rock and folk and fitting the five-minute public import limit. Keep the broader verified playlist catalog available for selection.

Persist enabled state, ordered tracks, minimum full-name hold, fixed cadence and reshuffling preference in D1. Enforce a minimum three-second complete-name hold. New selections require server-side metadata/audio verification. Reordering an existing pool must work during an Archive outage. Saves use optimistic revisions and immutable audit snapshots; student and guest roles cannot write. Expose only public song metadata and display settings to visitors. Aggregate actual successful splits only in the authenticated editor, never fabricate a run or expose student/job identities.

The frontend loads its first ready song without waiting for all checks. It verifies remaining tracks lazily with bounded concurrency and paced requests. Follow configured order on the first pass, skipping unavailable tracks, then optionally reshuffle each complete pass. Preserve seen tracks and order across reloads, avoid repeating the previous song at a shuffle boundary, and refresh public configuration within thirty seconds. Keep each fully displayed name for at least the configured hold, with a consistent cadence independent of title length. Typing, reduced motion and tab/touch acceptance keep their existing behavior.

Availability checks and import-duration permissions remain separate. Every actual import revalidates identity, duration and complete audio. Full-import checks are evidence of source compatibility, not claims that a paid separation completed. Existing successful-run counts come only from completed jobs with matching source attribution.

Use a two-second title reveal at the default six-second cadence. If an instructor configures a shorter available typing window, shorten the reveal to preserve the entire full-name hold. Reduced-motion visitors see the complete title immediately. Mobile uses the same inline placeholder and timing, with the Tab hint hidden.

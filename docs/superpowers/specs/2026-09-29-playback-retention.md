# Playback and retention corrections

The elapsed-time display must resume after a seek gesture ends, including a tap
that produces no value change, cancellation, lost capture and focus loss. Keep
one seek on committed change, not repeated seeks while dragging. Show elapsed
time on mobile. Prevent overlapping pending playback starts, allow cancellation,
and stop every stem if one fails.

Cloudflare account audio and owned split listings retain 90 days. Keep Railway
at 30 days. Deploy the matching R2 lifecycle policy without modifying multipart
abort rules. Previously deleted files cannot be recovered by this extension.
Instructor copy describes system prompt instructions for Listening Guide.

Shared Doorway callback diagnosis remains separate; this release does not change
SSO, quotas, provider keys or feature flags.

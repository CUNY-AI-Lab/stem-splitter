## Findings and changes

| Priority | Finding | Candidate treatment / remaining gate |
| --- | --- | --- |
| High | Legacy shared code and job-ID URLs are not individual student authorization | CAIL JWT verification + current Admission + job/stem ownership; unclaimed legacy records denied |
| High | Teacher roles and password throttle were local legacy mechanisms | CUNY sign-in replaces password entry in the candidate; Admission admins grant expiring local instructor roles with immutable revision history |
| High | Instructor access could expose other teachers' folders/jobs | Ordinary instructors now see only their own; explicit class enrollment/submission sharing still required |
| High | Reusing an upload URL could change an in-flight source | CAIL uploads are write-once with an atomic issued→uploading→ready state; cross-user writes and second PUT denied |
| High | Webhook payload could choose provider results | Candidate retrieves the job's stored prediction and ignores submitted output URLs; final audio URLs restricted to Replicate delivery hosts |
| High | Stem/provider responses were unbounded | Bounded provider JSON, 32 MiB per stem, response deadlines, redirects refused; full large-import memory and durable-ingestion qualification remains |
| High | New browser-local capture omitted attribution and compatibility checks | Conservative license matrix, source metadata persisted server-side, credit-bearing ZIP, immutable capture settings; complete license/version/legal edge review remains |
| Medium | Remixer shipped default-on in the feature branch | Restored literal false-default flag; one Crate moves between stations according to flag |
| Medium | CSS overrode native hidden attributes | Enforce `[hidden]`; browser tests now explicitly open the collapsed Listening Guide |
| Medium | Browser cache could expose a previous signed-in rack | Namespace rack storage by verified subject; no saved rack displayed before identity succeeds. Full logout/shared-device cleanup remains a live acceptance gate |
| Medium | Provider spend relied on a shared gate | Atomic UTC daily reservations plus supplemental edge rate limiting. No claim of exact dollar accounting or semester-budget integration |

## Blocking production promotion

1. Reviewed Doorway mount with prefix-safe assets, API/audio paths, exact audience,
   live CUNY sign-in/logout/revocation, and shared-device privacy proof.
2. Admission-backed course roster, instructor-course authority, per-class prompt
   settings, and explicit submission/share grants; no blanket instructor access.
3. Real paid Replicate and Listening Guide canaries across all source/split types.
4. Worker memory, byte-range audio, durable background ingestion, timeouts and
   concurrent load under a declared workload/spend envelope. Existing imports
   can still buffer large source bodies; do not advertise 100 MB stress readiness.
5. Analyzer reachability from Cloudflare without exposing a Railway private
   hostname; independently gated instrument/classifier promotion remains blocked.
6. AI Gateway comparative evaluation. Direct OpenRouter is unchanged; gateway
   routing or a different model must not be claimed tested.
7. Ownership-aware data import, prompt/history reconciliation, R2 retention and
   restore rehearsal, traffic-switch rollback, and human acceptance.
8. Independent SDK distribution provenance check or authorized registry install
   before final promotion (see `vendor/README.md`).

The merge sequence is: baseline main + feature branch → isolated migration and
security changes → reviewed Doorway integration → real acceptance/load/data
rehearsal → production promotion. Keep classifier expansion and Remixer promotion
as independently reversible flags, rather than bundling them into the hosting switch.
